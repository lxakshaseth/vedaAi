# Veda AI — Educator User Guide

## Getting Started

1. **Dashboard Overview**: Access class statistics, pass rates, and item-level diagnostic mastery across all cohorts.
2. **Uploading Exam Papers**:
   - Go to **Upload Assessment**.
   - Drop the **Master Question Paper (PDF)** on the left.
   - Drop the **Student Handwritten Answer Sheet (PDF)** on the right.
   - Click **Run AI Evaluation**.
3. **Reviewing Evaluated Answers**:
   - Inspect optical bounding boxes linking student handwriting directly with question rubrics.
   - Adjust marks inline with immediate live recalculation of percentages and letter grades.
4. **AI Teacher Toolkit**:
   - Create custom multi-tier rubrics for STEM, essays, and coding tasks.
   - Generate differentiated examination questions with exemplar answers.
5. **Exporting Records**:
   - Use the **Export Modal** to download CSV gradebooks for LMS import, JSON raw AST data, or printable student report cards.
